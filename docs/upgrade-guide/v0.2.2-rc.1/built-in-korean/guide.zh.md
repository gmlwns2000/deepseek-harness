# 内置韩语取代韩语语言包

[English](guide.md) | 中文

## 变更

locale 插件注册 `ko`（한국어），并提供 `common`、`settings.locale` 以及内置 UI 插件的字典；请求 `ko` 或 `ko-KR` 的浏览器或操作系统现在会以韩语打开。注册 `ko` 的第三方语言包会因语言或字典已注册而加载失败。

## 迁移

1. 在语言包的 client 入口中，删除 `ko` 的 `ctx.locale.addLanguage(...)`，以及内置插件已提供的命名空间下的 `ko` 字典注册。保留自己插件所拥有命名空间的 `ko` 翻译。
2. 如果语言包代表不同的韩语变体，为语言定义及其字典注册独立的 BCP 47 风格 id，例如 `ko-KP`，代替 `ko`。
3. 启用语言包并重新加载应用。确认启动时没有重复注册错误，且选择目标语言后显示对应译文。
